Neon Coast Cover Studio is an offline browser web application that transforms local photos and captions into stylized multi-panel cover art inspired by sun-drenched coastal aesthetics. The studio offers six layout arrangements, five atmospheric color grades, interactive panel panning and zoom controls, custom typography with sunset lettering, wanted heat meters, and one-click export for square, story, and landscape dimensions. Entered in make.fun's 'Make GTA 6 Cover Art' bounty — $250 in USDC in prizes, paid only to winners.

## Run it

```bash
node serve.ts
```

Open http://localhost:8080 in your web browser.
