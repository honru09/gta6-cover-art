Neon Coast Cover Studio is an offline browser web app that turns local photos and custom captions into GTA 6-style multi-panel cover art posters. It features 6 dynamic multi-panel layouts, 5 cinematic color grades (including sunset gradient-maps and neon night duotones), star heat meters, badge ribbons, and one-click export for square (1080×1080), story (1080×1350), and landscape (1920×1080) PNGs. Entered in make.fun's 'Make GTA 6 Cover Art' bounty — $250 in USDC in prizes, paid only to winners.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in a modern browser
```
